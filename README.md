# MCP_Client_Server
Learning to reate MCP server and client using python, langchain
I have also learnt how to integrate various mcps present in Claude Desktop - 
For integrating MCP in Claude desktop - Download claude desktop.
Then settings->developer->edit config->add respective mcp servers(what you want to use in the config file)-> close claude->re-open.
You will see your respective mcp servers added by clicking the '+' button in the chat bar->connectors.
This is the duckduckgo-search MCP present open source and I used for my learning. I also integrated airbnb mcp server.
